LASHISA サイト一式・担当者引き継ぎパッケージ
作成日：2026年9月16日

最新版のLASHISAサイト（Discord会話デモ・リアクション・集会所ガイド・アングラ風見出し）です。

【担当者の方へ】
1. ZIPを解凍してください。
2. docs/01_サーバー設置手順.txt を確認してください。
3. site フォルダの「中身5ファイル」を、公開したいディレクトリへ配置してください。
4. HTTPSのURLで表示と操作を確認してください。

HTML・CSS・JavaScriptで動く静的サイトです。ビルド、Node.js、PHP、データベースは不要です。
site/index.html を直接開いても基本的な表示確認はできますが、最終確認はサーバー上でお願いします。

【同梱内容】
site/index.html        ページ本文・Discord招待リンク
site/style.css         全体デザイン・スマートフォン対応
site/app.js            職種切替・案件詳細・会話デモ・リアクション
site/guild-hero.png    メインビジュアル
site/guild-guide.png   LASHISA版Discord集会所ガイド

docs/01_サーバー設置手順.txt
設置方法、確認項目、外部依存を記載。

docs/02_編集箇所と求人ブラッシュアップ.txt
更新方法と、求人情報として未確定の項目を記載。

docs/SHA256SUMS.txt
サイト5ファイルの整合性確認用ハッシュ。

【実装範囲】
Discord招待先：https://discord.gg/NmHsPZhzH
会話・案件・メンバー・リアクション数は説明用サンプルです。
Discord投稿の取得、応募の送信、案件管理、応募者情報の保存は実装していません。

このZIPは確認済みの現在のデザインを渡すためのものです。
給与・勤務条件等を新たに確定したり、実際の求人募集案件を追加したものではありません。
画像はAI生成・編集素材です。正確な実在の施設写真や実際のDiscord画面ではありません。

既存の限定公開環境とは独立して設置できます。認証情報やAPIキーは不要です。
